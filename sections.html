Section 1: الأساسيات والأجهزة والـ Topologies 📘

أغلبها موجود في المحاضرات (L1, L3, L4)، فالمحطة دي مراجعة سريعة + أنشطة المعيد. (⏱️ ١٥ دقيقة)

  • Computer network = مجموعة أجهزة (اتنين على الأقل) متوصلة بـ communication links، بتشارك موارد وبيانات.
  • ليه بنستخدمها: Resource sharing (printer، storage، Internet) · Data sharing · Communication (email، messaging، video calls) · Remote access.
  • المكونات الرئيسية: End devices (nodes) زي laptop وphone وprinter · Intermediary devices زي router وswitch وhub وaccess point وmodem وfirewall · Transmission media (سلكي زي fiber، لاسلكي زي Wi-Fi وBluetooth).
  • مكونات الاتصال: Sender → Transmission medium → Receiver + Protocol (= قواعد مشتركة؛ من غيرها communication may fail).

Point-to-Point

لينك مخصص بين جهازين بالظبط، وكل سعة اللينك بتاعتهم.

Multipoint

لينك واحد أو جهاز مركزي مشترك بين عدة أجهزة، والسعة متقسّمة بينهم.

🔀 Router ضد Switch (حيلة المعيد)

Router = BETWEEN networks، بيستخدم IP addressing، مثال: شبكة البيت ↔ الإنترنت. Switch = WITHIN a local network، بيستخدم MAC addresses، مثال: أجهزة الـ lab.
Client–Server: الـ client بيطلب داتا أو خدمة، والـ server بيعالج الطلب ويرجّع الرد. المسار المبسّط: Laptop → Access Point / Home network → Router → ISP (modem) → Web server.

🧵 Guided (Wired)

  • Twisted pair: أزواج أسلاك نحاس معزولة ملفوفة على بعض لتقليل الـ EMI والـ crosstalk. UTP (غير مغلّف) هو العادي في Ethernet LAN، وSTP فيه foil حماية.
  • Fiber optic: خيوط زجاج/بلاستيك بتنقل الداتا كنبضات ضوء، bandwidth عالي جداً ومحصّن ضد الضوضاء الكهربية.
  • Coaxial: موصّل نحاس + عزل + ضفيرة معدنية، لتلفزيون الكابل والإنترنت.

📡 Unguided (Wireless)

  • Radio waves: omnidirectional وبتخترق الحيطان؛ موبايل وWi-Fi وBluetooth.
  • Microwaves: تردد عالي، line-of-sight واتجاهية، لمسافات طويلة بين أبراج أو أقمار صناعية.
  • Infrared: تردد عالي جداً، مدى قصير، مبتخترقش الحواجز؛ ريموت كنترول.

الـ IP Address والـ Binary والـ Classes ⭐

عنوان الجهاز على الشبكة، وإزاي الـ class بيتحدد من أول رقم. (⏱️ ١٠ دقايق)

192.168.1.1

مثال 192.168.1.1: الـ ٣ octets الأولى network (في /24) والأخير host

  • IPv4 = 32 bit = 4 octets × 8 bits. كل octet من 0 لـ 255.
  • بيتقسم لجزء network (بيحدد الشبكة) وجزء host (بيحدد الجهاز).
  • بيعمل: يعرّف الجهاز على الشبكة · يوصّل الداتا للوجهة الصح · يخلّي الأجهزة تتكلم مع بعض.
  • مثال private IP في السلايد: 192.168.1.1 (جوه الشبكة المحلية). الـ public IP هو اللي بيتستخدم على الإنترنت.
  • 📖 الكتاب: IPv4 = 32 bit (حوالي 4.3 مليار عنوان). IPv6 = 128-bit hexadecimal وعناوينه «شبه غير محدودة».

🔢 الـ Binary: كل octet = 8 bits (جرّب)

كل bit قيمته ضعف اللي بعده: 128 · 64 · 32 · 16 · 8 · 4 · 2 · 1. الـ 1 = شغّال والـ 0 = مقفول، والرقم = مجموع القيم الشغالة. اضغط على أي bit أو اكتب رقم.

مثال السلايد: 192 = 128 + 64 = 11000000 · 168 = 10101000 · 1 = 00000001 · 192.168.1.1 = 11000000.10101000.00000001.00000001.

الـ Subnet Mask وحاسبة الـ IP ⭐

القناع اللي بيفصل الـ network عن الـ host، وإزاي تطلّع Network و Broadcast و First و Last و Hosts. (⏱️ ١٥ دقيقة)

  • Subnet mask = رقم 32 bit بيتستخدم مع الـ IP: الـ 1s = جزء الـ network، والـ 0s = جزء الـ host.
  • /24 معناها: أول 24 bit = 1s (مثال: 255.255.255.0، network 24 / host 8).
  • الـ router بيعمل AND بين الـ IP والـ mask عشان يطلّع الـ network address.
  • أمثلة CIDR من السلايد: /8 = 255.0.0.0 (network 8 / host 24) · /16 = 255.255.0.0 · /24 = 255.255.255.0 · /30 = 255.255.255.252 (network 30 / host 2).

🧮 الحاسبة (توضيح مني، بتوريك الخطوات)

أزرق = network bits · برتقالي = host bits

    4. Maximum hosts = 2h − 2 حيث h = 32 − prefix (بتشيل الـ network والـ broadcast).
    5. First usable = network + 1.
    6. Last usable = broadcast − 1.

    Subnetting ⭐ Borrowed bits · Block size

    تقسيم شبكة كبيرة لشبكات فرعية أصغر. (⏱️ ١٥ دقيقة)

    الفكرة: بنستلف (borrow) bits من جزء الـ host ونحولها لـ network bits، فيطلع عندنا subnets أكتر وكل واحد hosts أقل. مثال السلايد: 200.150.20.0 /26 (Class C، الـ default /24).

    1. الـ network والـ host: /26 = 26 network bits + 6 host bits.
    2. Borrowed bits n = new prefix − default prefix = 26 − 24 = 2.
    3. عدد الـ subnets = 2n = 2² = 4.
    4. Hosts لكل subnet = 2h − 2 = 2⁶ − 2 = 62.
    5. Block size (Magic number) = 256 − 192 = 64 ← كل subnet بيبدأ بعد 64 عنوان في الـ octet الأخير: 0 / 64 / 128 / 192.
    6. الـ mask /26 = 255.255.255.192.
    7. اكتب الـ subnets (network ← first ← last ← broadcast).

    قسمين، كل واحد فيه 5 أجهزة (4 PC + interface للـ router). بنستخدم شبكتين مختلفتين بالـ default mask:

    • Dept A = Class C 192.168.1.0/24: usable 254، مستخدم 5 ← 249 مهدرين.
    • Dept B = Class A 10.0.0.0/8: usable 16,777,214، مستخدم 5 ← 16,777,209 مهدرين.
    • إجمالي الهدر = 16,777,458 من 16,777,468 usable.

    ✅ Classless (CIDR) → أوفر

    نفس الـ Class C 192.168.1.0/24 بنقسّمه لـ subnetين بـ prefix أطول:

    • 5 أجهزة ← 2h − 2 ≥ 5 ← h = 3 ← prefix = 32 − 3 = /29 (mask 255.255.255.248، 2³−2 = 6 usable).
    • Subnet 1: 192.168.1.0/29 (.1 – .6، bc .7) · Subnet 2: 192.168.1.8/29 (.9 – .14، bc .15). الـ step = 8.
    • usable إجمالي 12، مستخدم 10 ← مهدر 2 بس.

    CIDR = Classless Inter-Domain Routing

    طريقة مرنة لتخصيص الـ IP بتستبدل الـ classes الثابتة (A, B, C) بـ variable-length prefixes (/24, /27, /29...). فوايده: Efficient IP allocation (أقل هدر) · Flexible subnetting (subnets بأحجام مختلفة) · Better network management · Route aggregation (دمج routes في route ملخّص واحد فيقلّ حجم الـ routing table).

    🧮 كام جهاز؟ ← أنهي prefix؟ (توضيح مني)

    القاعدة: أصغر h بحيث 2h − 2 ≥ عدد الأجهزة (احسب الـ router interface كجهاز لو السؤال قال كده)، وبعدين prefix = 32 − h.

    🧱 الـ VLSM (نشاط Section 4)

    VLSM (Variable Length Subnet Mask) = تقسّم نفس الشبكة لـ subnets بأحجام مختلفة حسب احتياج كل قسم. الخطوات:

    1. رتّب الأقسام من الأكبر للأصغر (عدد الأجهزة).
    2. لكل قسم: أصغر prefix يكفيه (2h − 2 ≥ hosts).
    3. أول subnet يبدأ من أول الشبكة، وكل subnet بعده يبدأ بعد آخر broadcast.
    4. وزّع العناوين: الـ router interface = first usable في كل subnet، والباقي للأجهزة، وتأكد إن مفيش overlap.

    مثال السلايد: 205.11.143.0/24 ← Sales 30 hosts ← /27 (205.11.143.0) · HR 20 hosts ← /27 (205.11.143.32) · IT 12 hosts ← /28 (205.11.143.64). الـ router: G0/0 .1 (Sales) · G0/2 .33 (HR) · G0/1 .65 (IT).

    🧠 /31 و /32 (Research task في السلايد، والإجابة من فهمي العام مش من المصادر): /31 = عنوانين بس، بتتستخدم في وصلات point-to-point بين router وrouter (بالقانون العادي 2¹ − 2 = 0، لكن الاستخدام العملي بيسمح بالعنوانين). /32 = عنوان واحد بس لجهاز واحد (زي loopback أو host route).

    Section 3: Packet Tracer 🛠️

    عملي، بس ممكن يتسأل منه نظري (الكابلات، الـ gateway، الأوامر). (⏱️ ١٠ دقايق)

    Straight-through

    بيوصّل أنواع مختلفة من الأجهزة (PC ↔ Switch، Router ↔ Switch). نفس الـ standard على الطرفين (T568B–T568B).

    Crossover

    بيوصّل نفس النوع (PC ↔ PC، Switch ↔ Switch، Router ↔ Router). T568A على طرف وT568B على التاني، فالـ transmit والـ receive بيتبدلوا (pins 1↔3، 2↔6).

    Console

    لتهيئة الجهاز بس (مش للاتصال العادي): من الـ serial port (RS-232) في الـ PC لـ console port في الـ router/switch. في Packet Tracer اختار كابل «Console».

    الـ UTP فيه 8 أسلاك في 4 أزواج ملفوفة، والـ connector هو RJ-45. ألوان T568B (1→8): أبيض/برتقالي، برتقالي، أبيض/أخضر، أزرق، أبيض/أزرق، أخضر، أبيض/بني، بني. وT568A بتبدل الأخضر والبرتقالي.
