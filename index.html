📋 اللي بيتكرر في الميدتيرم السابقة (د. طارق — ساعة، ٢٠ درجة: ١٠ MCQ + ٥ + ٥، وفيها أسئلة «صحّح الغلط من غير نفي»):
  • «كل الأجهزة متوصلة بـ hub واحد» = Star (٣ سنين ورا بعض) · فوايد الـ layering (٣ سنين) · CSMA/CD: التصادم ممكن يحصل والخوارزمية بتكتشفه وتتعامل معاه · مثال الـ encapsulation (TCP ثم IP ثم Data-link header + trailer).
  • أخطاء بتتكرر: point-to-point مش «أكتر من جهازين» (ده multipoint) · الـ routing في الـ Network layer مش الـ Transport · half / full duplex وsimplex · وحدة الـ Data link هي الـ frame · الـ presentation مش في TCP/IP · Router vs Switch.
  • تعريفات: Reliability (وفرقها عن availability) · CRC (الاسم + مثال) · Latency ≠ Bandwidth · مزايا وعيوب twisted pair وfiber ومعايير اختيار الوسط.
  • اتضاف في صفحة السكاشن (مش جوه المحاضرات):IPv6 = 128 bit · Class A / B / C (أول octet في Class B من 10000000 لـ 10111111، وClass A أكبر عدد hosts) · الـ private IP مش بيتعمله route على الإنترنت · الـ router بيستخدم الـ Network ID. ده كله في صفحة السكاشن (من Section 2 + 4 وفصل ٥ من الكتاب).
